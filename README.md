## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Windows sekali klik

- Klik dua kali `Jalankan.bat` untuk memasang dependensi (bila perlu), menjalankan server, dan membuka aplikasi di browser.
- Klik dua kali `Hentikan.bat` untuk menghentikan server Vite beserta proses turunannya.
- Alternatif terminal: `npm run start` dan `npm run stop`.
